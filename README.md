## What is this program?
This is how banks work in our world. It is a representation of how a bank sends money from person to person. Server.js is a bank. Request.js is a client.

## How does it work?

We have accounts.json file. It has all data about our clients and their money. Use function "sendData()" from request.js to send some money from person "one"(first arg in the function) to person "two" (second arg) and add amount of money. Run the script request.js. Check changes in accounts.json file. But first, of course, start the local server by typing "npm start" in terminal of your IDE. Have fun!
